Namen in bulk toevoegen/corrigeren

Optie A: plak twee kolommen (afkorting, naam) rechtstreeks vanuit Excel hieronder — dat plakt automatisch tab-gescheiden.
Optie B: upload een los Excel/CSV-bestand met in de eerste kolom de afkorting en in de tweede kolom de naam.

Coördinatoren markeren (geen les, maar wel op school)

Voor leerkrachten met een coördinatorrol e.d.: zij hebben soms een dag zonder lessen, maar zijn dan wél op school. Markeer ze hier zodat ze nooit automatisch als "niet op school" voorgesteld worden — ook niet na een nieuwe import van het rooster.

Plak een lijst afkortingen (één per regel, of met status erbij: afkorting;wel op school / afkorting;vrije dag), of upload een los Excel/CSV-bestand met dezelfde opbouw.

Delen met collega's

De tool bewaart alles enkel lokaal in jouw browser — een collega die dezelfde pagina opent, start met een lege tool.

Optie A — bestand doorsturen

Exporteer je volledige configuratie als één bestand en stuur dat door (Smartschool, e-mail…). Je collega importeert het.

Optie B — automatisch bijwerken via GitHub

Let op — privacy: een GitHub Pages-site is standaard publiek zichtbaar voor iedereen met de link, ook bij een privé-repository (tenzij je een betalend Enterprise-account hebt). Plaats daarom nooit een configuratiebestand mét volledige namen op GitHub — laat het vinkje "Namen niet meenemen" hierboven aangevinkt. Zo staat op GitHub enkel het rooster met afkortingen (bv. "MM", "PK") in plaats van volledige namen gekoppeld aan iemands lesuren.

Werkwijze: exporteer zonder namen, upload dat bestand als bv. configuratie.json naast vergadermoment-planner.html op GitHub Pages. Elke collega vult dan **lokaal, eenmalig** de volledige namen aan bij Instellingen → Leerkrachten beheren → "Namen in bulk toevoegen" (die naamkoppeling blijft nadien lokaal bewaard, ook bij een volgende keer ophalen van GitHub — enkel het rooster zelf wordt ververst). De naamlijst zelf deel je apart, via een besloten kanaal zoals Smartschool, nooit via GitHub.

Tip: bij dezelfde GitHub Pages-site volstaat de bestandsnaam configuratie.json; hosted het elders, gebruik dan de volledige link (https://…).
